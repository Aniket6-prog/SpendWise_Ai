# SpendWise AI — Smart Student Expense Management System

A full-stack reactive web application built for college students to track expenses, split flat/roommate bills (4 to 6 members), evaluate purchase decisions, and get AI financial advice in **Indian Rupees (₹ - INR)**.

## 🚀 Features

1. **Hello Student 🎓 Personal Dashboard**:
   - Total spent vs monthly budget gauge.
   - Daily breakdown **Pie/Donut Chart**.
   - Monthly trend **Day-by-Day Area Line Chart**.
   - **Yearly (Jan–Dec) Record Line Chart** with budget caps.

2. **Complete Authentication Engine**:
   - Student Login & Signup with local storage persistence.
   - Interactive **Forgot Password modal with OTP verification**.
   - Pre-configured demo user: `alex@student.edu` / `Password123!`.

3. **Flat Roommates Bill Splitter (4–6 Members)**:
   - Presets for Rent, Electricity, Wi-Fi, Cook/Maid Salary, LPG Gas, Groceries.
   - Automatic calculation of "Who owes Whom" minimum transactions ledger.

4. **AI Purchase Evaluator**:
   - Calculates meal equivalents (e.g., mess meals) and budget impact score before buying.

5. **SpendWise AI Chatbot Assistant**:
   - Interactive financial advisor tailored for college life.

6. **Dark / Light Theme Engine**:
   - Built-in theme switch with persistent preference.

## 🛠️ Tech Stack & Setup Instructions

### Frontend Stack:
- **React 18** + **Vite**
- **Tailwind CSS**
- **Recharts** (Interactive Pie & Line charts)
- **Lucide React** (Icons)

### Backend (MERN Stack Architecture):
For full Node.js / Express + MongoDB deployment:
1. `npm install`
2. `npm run dev`
